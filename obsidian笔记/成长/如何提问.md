### 一、ORID 提问模型（职场沟通、问题梳理、教练辅导核心工具）

#### 1. O（Objective：事实 / 目标）

- **核心逻辑**：提问的起点，用客观、无情绪的事实切入，避免主观判断，为后续沟通建立统一基础（无事实则无共识，易陷入争论）。
- **关键原则**：只问 “发生了什么”“是什么”，不掺杂 “你觉得”“我认为” 等主观表述。
- **多场景话术案例**：
    
    - 面试场景：“你上一份工作中负责的 XX 项目，具体的执行流程是怎样的？”“这个项目的核心目标是什么，最终达成了哪些量化结果？”
    - 管理场景（对下属）：“我们上周确定的 XX 任务，目前推进到了哪一步？”“这个任务的关键节点有哪些，现在是否有未达成的节点？”
    - 同事沟通：“昨天会议上提到的 XX 方案，你当时记录的核心要求是什么？”“这份数据报告的统计周期是多久，数据源来自哪里？”
    
- **避坑点**：不追问无关细节（如 “你当时为什么选这个流程”，这是 I 环节的问题），不加入评价（如 “你这个流程好像不太合理”）。

#### 2. R（Response：感受 / 反应）

- **核心逻辑**：提问的关键，通过挖掘情绪与感受构建信任 —— 潜台词是 “我懂你”，只有对方感受到被理解，才会愿意暴露真实想法。
- **关键原则**：结合对方的情绪状态调整提问，用 “感受词” 引导表达（头疼、开心、焦虑、为难等）。
- **多场景话术案例**：
    
    - 下属抱怨工作时：“面对这个反复修改的需求，你当下的感受是什么？”“这件事最让你觉得棘手的地方在哪里？”
    - 同事合作遇阻时：“和 XX 部门对接时，对方的反馈让你觉得不舒服的点是什么？”“这件事推进不下去，你心里是不是有点着急？”
    - 面试候选人聊过往经历：“这个项目最终成功落地时，你最有成就感的瞬间是什么？”“当时遇到资源不足的问题，你内心的第一反应是什么？”
    
- **实操技巧**：观察对方的语气、表情（皱眉、叹气、微笑），针对性提问 —— 对方微笑就问 “开心点”，皱眉就问 “为难点”，避免反向提问（如对方明显焦虑，却问 “你觉得这件事很轻松吗”）。

#### 3. I（Interpretation：解读 / 原因 / 影响）

- **核心逻辑**：深挖真相的核心环节，通过 “层层追问” 让对方从 “说感受” 过渡到 “说原因”，同时暴露问题本质、潜在影响，相当于 “剥洋葱”。
- **关键工具**：三大追问话术 ——“为什么”（挖原因）、“然后呢”（挖结果）、“还有吗”（挖细节）。
- **完整案例演示**（下属反馈 “和领导沟通不畅”）：
    
    1. O：“你和领导最近一次沟通不畅的事情，具体是在什么场景下发生的？”（事实）
    2. R：“这件事让你觉得最头疼的是什么？”（感受）
    3. I：“为什么你觉得这次沟通会不顺畅？”（挖原因）→ 下属：“他打断我说话，不让我把方案讲完。”
    4. 追问：“他打断你之后，然后呢？这件事带来了什么影响？”（挖结果）→ 下属：“方案没讲清楚，领导否定了，项目推迟了。”
    5. 再追问：“除了打断你，还有其他让你觉得沟通受阻的点吗？”（挖细节）→ 下属：“他总用自己的经验否定我，不听我的实际执行难点。”
    6. 循环追问（结合 R）：“当他用经验否定你的时候，你心里是什么感觉？这对你后续提方案有什么影响？”（再挖感受 + 影响）
    
- **避坑点**：不急于发表自己的解读（如 “我觉得是你没表达清楚”），让对方自主说出原因；不中途打断，等对方说完再追问。

#### 4. D（Decision：行动 / 下一步）

- **核心逻辑**：提问的最终目的，引导对方主动说出行动方案（自己说的行动，执行力远高于 “被安排的行动”）。
- **关键时机**：当对方开始重复表述（说车轱辘话），说明感受和原因已倾诉充分，可切入 D 环节。
- **多场景话术案例**：
    
    - 辅导下属：“基于刚才聊的这些情况，你接下来打算怎么做？”“除了这个方案，还有其他可尝试的办法吗？”
    - 解决同事矛盾：“为了避免下次再出现对接不畅，你觉得我们各自可以做些什么调整？”
    - 面试收尾：“如果拿到这个 offer，你入职后第一步会做什么来快速融入团队？”
    
- **实操技巧**：
    
    1. 用 “还有吗” 帮对方拓展思路（避免单一方案的局限性）；
    2. 后续跟进提问：“这个行动你打算什么时候开始？”“过程中需要我提供什么支持？”（把行动落地到具体时间和资源）；
    3. 肯定对方方案（如 “这个思路很全面，能解决之前提到的核心问题”），强化执行意愿。
    

### 二、SPIN 提问模型（销售谈判、商务合作、高价值产品推广核心工具）

#### 1. S（Situation：背景 / 基本情况）

- **核心逻辑**：轻量级引入口，仅了解必要的基础信息，目的是为了自然过渡到 “痛点” 提问，而非 “查户口”。
- **关键原则**：先说明提问目的→再问 1-2 个核心问题→不追问细节（细节可后续穿插补充）。
- **成熟话术案例**：
    
    - B2B 销售（卖办公软件）：“今天想和你探讨下如何提升你们团队的协作效率，方便问一下你们现在用的是什么协作工具吗？”“团队大概有多少人在使用这个工具？”
    - B2C 销售（卖高端健身私教课）：“我看你之前咨询过健身计划，想了解下你目前主要是想改善体态，还是减脂增肌呀？”“平时每周大概能抽多少时间健身？”
    - 商务合作洽谈：“我们希望能和贵公司达成内容合作，先简单了解下你们目前的核心用户群体是哪些人？”
    
- **避坑点**：
    
    - 不连续追问隐私 / 敏感信息（如 “你们公司年营收多少”“你个人月收入多少”）；
    - 不停留在此环节（最多 3 个问题，否则会让对方觉得 “被调查”，如相亲时连环问 “年龄、存款、房车”）；
    - 顶尖技巧：后续聊痛点 / 影响时，可穿插补充背景提问（如 “你刚才说工具卡顿，那你们团队每天用这个工具处理多少条数据呀？”），让信息更完整。
    

#### 2. P（Problem：痛点 / 挑战）

- **核心逻辑**：挖掘对方的真实需求 —— 所有合作 / 购买行为的本质，都是 “解决痛点”，只有找到痛点，才能精准匹配方案。
- **关键原则**：大胆直接问，不绕弯；若对方不暴露痛点，说明未建立信任，需回到 S 环节（补充背景）或用 ORID 的 R 环节（挖感受）铺垫。
- **多场景话术案例**：
    
    - B2B 销售（卖客户管理系统）：“目前用的协作工具，在客户信息管理上有没有让你觉得不方便的地方？”“处理客户跟进记录时，最耗时的环节是什么？”
    - B2C 销售（卖高端护肤品）：“你现在用的护肤品，有没有解决不了的皮肤问题（比如敏感、暗沉）？”“在选择护肤品时，你最担心遇到什么问题？”
    - 商务合作（内容推广）：“你们目前做用户增长，遇到的最大瓶颈是什么？”“现有推广渠道有没有让你觉得效果不达预期的地方？”
    
- **信任甄别技巧**：
    
    - 若对方直接说痛点（如 “我们现在客户数据分散，找起来很麻烦”），说明信任已建立，可直接进入 I 环节；
    - 若对方回避（如 “还好吧，没什么大问题”），需回到 S 环节补充提问（如 “你们现在客户数据是存在多个表格里吗？”），或用 R 环节破冰（如 “平时处理客户数据时，会不会觉得很繁琐？”）。
    

#### 3. I（Implication：影响 / 后果）

- **核心逻辑**：放大痛点的 “痛感”—— 对方可能觉得痛点 “无所谓”，但放大其对工作 / 生活的具体影响后，会产生 “必须解决” 的迫切性。
- **关键技巧**：结合 “客观影响”（效率、成本、结果）和 “主观感受”（焦虑、麻烦、挫败）双重放大，可复用 ORID 的 R 环节话术。
- **完整案例演示**（B2B 销售卖客户管理系统，对方痛点 “客户数据分散”）：
    
    1. P：“客户数据分散，给你们带来的最大麻烦是什么？”（痛点）→ 对方：“找客户信息要翻多个表格，浪费时间。”
    2. I（客观影响）：“这种浪费时间的情况，会不会导致跟进客户不及时，进而影响成交率？”“如果团队多人对接同一客户，数据分散会不会出现重复沟通、遗漏需求的情况？”
    3. I（主观感受）：“每次急着找客户信息却找不到时，你会不会觉得很焦虑？”“长期用这种方式处理数据，会不会让你觉得工作效率低，成就感不足？”
    
- **行业适配案例**：
    
    - 教育行业（卖升学辅导）：“如果现在不解决孩子的薄弱科目，会不会影响后续的升学考试？”“看到孩子成绩提不上来，你是不是也觉得很着急？”
    - 制造业（卖节能设备）：“现在的设备能耗高，长期下来会不会增加很多运营成本？”“如果后续环保检查不达标，会不会影响工厂正常生产？”
    

#### 4. N（Need：需求 / 代价 / 解决方案）

- **核心逻辑**：让对方明确 “为解决痛点愿意付出什么”（时间、金钱、精力），同时自然推出自己的产品 / 方案，让对方觉得 “方案适配我的需求，代价值得”。
- **关键原则**：先让对方说 “理想方案” 和 “可承受代价”，再推自己的产品（不先报价格 / 方案，避免被动）。
- **完整案例演示**（卖企业培训课程，对方痛点 “中层管理能力不足”）：
    
    1. S：“你们公司中层团队大概有多少人？目前主要负责哪些工作？”（背景）
    2. P：“在带团队的过程中，中层管理最欠缺的能力是什么？”（痛点）→ 对方：“不会带新人，团队执行力差。”
    3. I：“这种情况会不会导致新人流失率高，核心工作推进慢？”“作为老板，看到中层带不动团队，你是不是觉得压力很大？”（放大影响）
    4. N（问代价）：“为了提升中层的管理能力，你觉得公司能承受的培训预算大概是多少？”“你希望培训后能达到什么效果（比如新人留存率提升多少）？”
    5. N（推方案）：“你刚才说的预算和效果，正好和我们的‘中层管理实战营’匹配 —— 课程聚焦新人带教和执行力提升，预算比你预期的低 20%，还能提供后续 3 个月的落地辅导，你觉得怎么样？”
    
- **避坑点**：
    
    - 不直接报价格（先问对方可承受代价，再匹配）；
    - 不夸大方案效果（结合对方的痛点和影响，精准对应，如对方要 “新人带教”，就不说 “战略规划”）；
    - 高净值用户（B2C 客单价≥1 万）可多问 “还有别的需求吗”，普通用户简化流程，避免过度复杂。
    

### 三、模型灵活运用与关键避坑

#### 1. 两大模型的结合技巧

- 用 ORID 的 R（感受）补充 SPIN 的 P（痛点）：对方暴露痛点后，用 R 环节提问放大情绪（如 “这个痛点让你最头疼的是什么”），加深信任；
- 用 SPIN 的 I（影响）补充 ORID 的 I（解读）：ORID 聊问题时，用 SPIN 的 I 放大影响（如 “这个问题不解决，后续会带来什么麻烦”），推动行动；
- 场景适配：职场内部沟通（绩效面谈、同事协作）以 ORID 为主，销售 / 商务合作以 SPIN 为主。

#### 2. 常见错误总结（必避）

- 跳过感受直接给行动：如 “你别抱怨了，赶紧把方案改了”（无信任，对方必抵触）；
- 背景提问查户口：如销售连环问 “你们公司营收多少、利润多少、客户多少”（引发反感，直接终止沟通）；
- 未放大痛点就推产品：如 “我们的产品很好，你买吧”（对方觉得 “我没那么需要”，拒绝率高）；
- 追问时打断对方：如对方说 “我觉得领导不重视我”，你立刻接 “其实是你没做好”（关闭沟通通道）。
