# 网贷敢给银行都不敢贷的人放贷的核心原因与流程解析

### 一、核心逻辑：为何网贷敢放贷给 “银行都不敢碰” 的人？

银行放贷的核心是**风控与还款能力**（查流水、押房本、审征信），而网贷的逻辑完全相反 —— 他们**从没想过让借款人本人还钱**，而是构建了一套以 “人质” 为中心的收割闭环：

|维度|银行逻辑|网贷逻辑|
|---|---|---|
|目标客户|有收入、有抵押、信用好的优质客户|无收入、无抵押、看似还不起的 “完美受害者”|
|风控核心|评估借款人还款能力|评估借款人社会关系价值、面子成本、家庭兜底能力|
|盈利来源|借款人按时还款的利息|借款人背后家庭几十年积累的财富|
|风险转移|自身承担坏账风险|通过 “社会关系质押 + 以贷养贷” 转移风险|

#### 两把 “致命镰刀”：

1. **第一把镰刀：社会关系质押（最核心手段）**
    
    - 网贷不查征信，而是**强制读取通讯录、填写亲友电话**（父母、辅导员、室友）
    - 这是一种隐蔽的**资产证券化**：借款人虽无钱（不良资产），但他的**社会关系网、面子、前途、声誉都是明码标价的抵押物**
    - 一旦违约，启动的不是法律程序，而是 **“社会性死亡核打击”**（疯狂轰炸电话、P 图群发），精准利用**中国式家庭的 “面子” 与 “护犊子” 心理 **—— 父母为保孩子前途会砸锅卖铁还款
    - 本质：借款人只是**撬动家庭储蓄的杠杆**，猎人真正瞄准的是猎物身后的保护者
2. **第二把镰刀：反向筛选机制（黑暗博弈论）**
    
    - 设置 ** 极高利息（日息万分之五）、砍头息（借 1000 到手 700）** 等霸王条款，自动过滤理性、有金融常识的人（他们不是目标）
    - 留下三类 “完美猎物”：
        - 极度缺乏社会经验、对金钱无概念的 “白纸”（如大学生）
        - 被欲望冲昏头脑、急需用钱填窟窿的 “赌徒”
        - 处于绝境、什么字都敢签的 “边缘人”
    - 这些人的共同点：**认知能力无法覆盖欲望或困境**，是最易被收割的群体
3. **心理陷阱 + 文化包装：降低借贷痛感，美化负债行为**
    
    - **即时满足麻痹理性**：APP 设计顺滑，人脸识别 3 秒到账，**麻痹前额叶皮层（负责理性规划的区域）**，让还款的 “延时痛苦” 变得迟钝
    - **文化洗脑**：用 “年轻不留白”“爱自己就要买买买” 等文案，把**负债偷换成时尚、独立的生活方式**，贩卖 “尊严的幻觉”
4. **终极玩法：以贷养贷的 “共谋” 陷阱**
    
    - 当第一笔借款逾期，放贷人会 “贴心” 推荐新平台（行话叫 “倒带”），让你用新债还旧债
    - 对放贷人：**金蝉脱壳**（本金 + 高息落袋，风险转移给下家）+ **榨干最后价值**（像报废电池一样榨取剩余信用额度与家庭兜底能力）
    - 债务滚雪球：5000→2 万→10 万，买手机的钱最终滚成房子首付，借款人被迫成为**诈骗链条的共谋者**（为掩盖谎言编造更大谎言）
5. **数据流通的 “灰色网络”**
    
    - 平台间数据共享，借款人信息（身份证、通讯录、消费习惯）被打包卖给上下游产业
    - 一个网贷申请 = 几十个骚扰电话 + 杀猪盘精准围猎，因为在大数据眼里，这类人是 **“全天下最完美的待宰羔羊”**

### 二、网贷贷款的典型流程（视频描述版）

1. **下载 APP，注册账号**：界面设计 “顺滑”，降低心理门槛
2. **强制授权关键信息**（最核心步骤）：
    - 读取手机通讯录（必须），填写父母、辅导员、室友等亲友电话
    - 人脸识别（3 秒完成），无需线下审核
    - 部分平台要求 “裸条” 或额外个人信息，进一步增加质押筹码
3. **签署霸王条款**：
    - 日息万分之五（年化 18%+）、砍头息（借 1000 到手 700）、高额违约金等**不平等条款**
    - 借款人往往因急需用钱或缺乏金融常识**忽略细节**
4. **极速放款**：
    - 动动手指，3 秒到账，制造 **“无痛获取” 的快感 **，麻痹理性判断
5. **贷后 “收割” 流程**：
    - 逾期初期：“贴心” 推荐新平台（“倒带”），引导以贷养贷
    - 债务爆发：启动通讯录轰炸、P 图群发等 “社会性死亡” 催收，逼迫家庭还款
    - 终极榨干：当家庭兜底能力耗尽，借款人被抛弃，成为 “榨干后随手丢弃的电池”

### 三、本质：现代社会的 “灵魂空心化” 危机

网贷泛滥的根源不仅是监管问题，更是**消费主义驯化的社会病理问题**：

- 资本通过媒体重新定义价值：**消费 = 身份，不消费 = 废物**，制造 “撕裂般的贫困感”（不是吃不饱，而是无法通过消费证明存在感）
- 年轻人心智未成熟 + 消费欲望膨胀 + 现实收入有限 = 网贷 “完美温床”
- 只要 “消费即正义” 的价值观不变，无论关停多少平台，恶之花仍会换马甲生长

### 四、生存指南（视频建议）

1. 建立**坚硬内核**：拒绝透支未来换光鲜，那是枷锁不是勋章
2. **学会说 “不” 的底气**：真正的强大不是拥有最新款手机，而是对不合理要求说 “不” 的能力
3. 打破面子枷锁：当被威胁爆通讯录时，**坦白一切切断源头**比借钱填坑更有效，面子在生死边缘一文不值
