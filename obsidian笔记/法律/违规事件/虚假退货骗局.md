文档中涉及的多起虚假退货 “薅羊毛” 诈骗案件，核心均是**利用网购平台 / 商家的系统、审核漏洞，通过虚构事实、隐瞒真相的方式，让平台 / 商家产生错误认知并完成退款，从而非法占有商品，最终通过转卖牟利或囤积自用**，不同案件的操作细节略有差异，整体可提炼出**通用核心套路**，并结合个案形成**不同操作变体**，具体总结如下：

### 一、通用核心套路（全案共通步骤）

#### 步骤 1：偶然发现漏洞，滋生侥幸心理

作案人均是在日常网购、退货过程中，意外发现平台 / 商家的规则或系统漏洞，且发现该漏洞可实现 “不花钱拿商品”，侥幸心理占据主导，萌生非法牟利 / 占便宜的想法。

常见漏洞类型包括：平台不核验实际退货物流即退款、退款后系统仍自动发货、快速退款与商家实物确认存在时间 / 信息差、退货审核把关不严等。

#### 步骤 2：小额试探操作，确认漏洞可钻

初期均以**小金额、小单量**进行尝试，反复验证漏洞的真实性，确认多次操作后未被平台 / 商家发现、追责，为后续扩大作案规模做铺垫。例如台州程某先从几十元的商品入手，多次成功后才逐步提高订单金额。

#### 步骤 3：扩大作案规模，批量非法占有商品

在试探成功后，通过增加下单量、提高订单金额、提升作案频率等方式，大规模利用漏洞获取商品，部分案犯还会通过各类手段规避平台排查，降低被发现的概率。

#### 步骤 4：虚构退货 / 交易事实，完成退款闭环

这是套路的**核心关键**，作案人通过制造 “已退货”“已取消订单” 的虚假表象，让平台 / 商家基于**错误认知**完成退款操作，而实际并未返还真实商品，最终实现 “零成本获商品”。

#### 步骤 5：处置商品 + 挥霍 / 囤积，实现非法目的

作案人对骗取的商品进行两种处置：一是**转卖牟利**，将商品低价转手到二手平台等渠道，获取现金后大肆挥霍；二是**囤积自用**，将商品大量囤在家中，满足个人生活需求。

### 二、不同案件的操作变体（核心套路下的个性化手段）

三起典型案件在通用步骤的基础上，根据目标平台 / 商品的特点，采用了不同的具体操作方式，形成了三种套路变体，具体如下：

#### 变体 1：上海吕某（化妆品平台，涉案 476 万）—— 多账号 + 虚假物流号，批量虚假退货

1. 账号准备：使用本人、亲友账号，还**有偿租用他人账号**，解决单账号下单限制，实现批量下单；
2. 虚假退货：购买**刷单物流账号**制作假的退货凭证，仅提交退单号却不实际返还商品；
3. 牟利方式：平台基于假退单号完成退款后，将化妆品低价转卖，获赃款 401 万元并大肆挥霍。

#### 变体 2：浙江程某（商超线上平台，涉案 20 余万）—— 利用发货 BUG，退款后坐等收物，纯自用囤积

1. 无额外操作成本：无需制作虚假凭证，仅利用平台 **“退款后仍自动发货” 的系统 BUG**，下单付款后申请退款，钱款退回的同时仍能收到商品；
2. 高频次下单：每两三天就操作一次，累计下单 400 余单、3000 多件商品，覆盖商超全品类；
3. 商品处置：全部囤积自用，家中遗留 6 万余元未拆封商品，无转卖牟利行为。

#### 变体 3：上海方某（枕头官方店铺，涉案 176 万）—— 代下单 + 空包退货，利用时间 / 信息差牟利

1. 组织下单：安排**带下单人员**批量在官方店铺下单，解决个人操作效率问题；
2. 虚假退货：寄送**空包 / 假包裹**（重量仅 0.01-0.02kg，与真实枕头包裹重量差距极大），制造 “已退货” 的假象；
3. 利用信息差：钻平台**快速退款与商家退货确认的时间 / 信息差**漏洞，平台先完成退款，商家后续发现未收到真实货物时已造成损失；
4. 牟利方式：将骗取的枕头以 170-190 元 / 个的价格转卖，获赃款 114 万元。

### 三、此类套路的核心作案关键

1. **精准利用漏洞**：均瞄准平台 / 商家在退货审核、系统设计、流程衔接上的短板，这是整个套路的前提；
2. **虚构事实隐瞒真相**：通过假物流号、空包、单纯利用系统 BUG 等方式，让平台 / 商家误以为 “交易已取消”“商品已退回”，属于诈骗罪的核心构成要件；
3. **非法占有为目的**：从初期试探到大规模操作，均以无偿获取商品 / 牟利为目标，并非正常的网购退换货，主观上具有明显的非法占有意图。
